# Resend Email Integration & Notification System

## Objective

Integrate the Resend Email API into the application to provide reliable, professional, and automated email communication between the business, customers, and administrators.

The email system should ensure that important events never go unnoticed, improve customer trust, and reduce the need for manual communication.

The email experience should be fast, reliable, responsive, mobile-friendly, and visually consistent with the Katenovas Collections brand.

---

# General Requirements

The application must securely integrate the Resend API using server-side environment variables.

The API key must never be exposed to the browser.

All email sending should occur through secure backend endpoints.

The system should gracefully handle temporary failures and retry when appropriate.

Every email event should be logged for auditing and troubleshooting.

# AI Integration

The AI should trigger emails automatically when appropriate.

Customer requests product information requiring manual review.

Refund request submitted.

Urgent complaint received.

The seller should receive an email even if not currently logged into the dashboard.

---

# Smart Email Behaviour

Avoid duplicate emails.

Prevent repeated notifications.

Queue emails during temporary failures.

Retry automatically.

Log failures.

Notify admins if repeated failures occur.

---

# Security

Store the Resend API key only in secure environment variables.

Never expose it to the client.

Validate every outgoing email request.

Rate-limit abuse.

Log all email activity.

---

# Performance

Send emails asynchronously.

Email delivery should never block checkout, order creation, or user actions.

If email delivery fails temporarily, continue processing the order and retry email delivery in the background.
